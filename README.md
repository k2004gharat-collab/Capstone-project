## Getting started

Clone the repository:

```bash
git clone https://github.com/k2004gharat-collab/Capstone-project.git
cd Capstone-project
```

Install dependencies and start the app:

```bash
npm install
npm run dev
```

The settings form is the main screen. Run tests with:

```bash
npm test
```
